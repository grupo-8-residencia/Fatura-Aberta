# Critérios de aceite

Critérios do produto vindos das regras centrais. Os critérios numéricos específicos entram quando o time os definir.

## Do produto

- [ ] Todo item do cartão de decisão mostra o nível (A, B ou C).
- [ ] Todo achado de nível B mostra a fonte e a data da tabela oficial usada.
- [ ] Toda citação traz ato, dispositivo e vigência.
- [ ] Só achados de nível A são emitidos automaticamente.
- [ ] Nenhuma tela ou texto afirma "ilegal" nem estima restituição.
- [ ] O usuário confirma os campos extraídos de foto antes da análise.
- [ ] Fatura real não é armazenada no repositório.
